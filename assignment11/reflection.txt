1. Reflection on the differences between static and interactive visualizations:
Static visualizations, like the Matplotlib and Pandas charts created in Tasks 1 and 2, offer a fixed snapshot of data. They work great for standard reports or presentations where you want to show a single, clear conclusion. Interactive visualizations, like the Plotly scatter plot in Task 3, let the user actively engage with the graphic. Being able to hover for specific data points, zoom in, or toggle data categories makes it much easier to explore a dataset deeply without having to change the underlying code.

2. Advantages of using dashboards for real-time data exploration:
Dashboards are highly valuable because they turn raw datasets into an easy-to-read, live workspace. Instead of forcing someone to run a new script every time fresh data comes in, a dashboard can automatically refresh and display the latest information. This allows teams to instantly track changes, spot trends, and explore data on their own, making it a powerful tool for monitoring ongoing projects or live operations.

3. How interactive tools like Plotly improve data communication in professional settings:
In a professional setting, not everyone has a technical background or knows how to read raw database tables. Interactive tools like Plotly bridge this gap by making data clean and approachable. Instead of cluttering a slide with too much text or multiple static charts, an interactive HTML plot allows stakeholders to look at the big picture or hover over specific points to answer their own questions. This makes meetings more productive and helps teams make data-driven decisions faster.
